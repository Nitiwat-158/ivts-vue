## T4 Current Behavior

- Current system is a Python-based camera tracking project under `ai-track`.
- The API exposes `/api/cameras`, `/api/vehicles/recent`, `/api/vehicles/full-route`, and `/api/vehicle/timeline/{global_id}`.
- The DB stores cross-camera identities in PostgreSQL with pgvector for ReID vectors.
- Tools support calibration, mask picking, fake data seeding, ReID analysis, live fusion backfill, and offline lookup.
